# Zomato EDA Project

## 📌 Project Overview
This project focuses on Exploratory Data Analysis (EDA) of the Zomato restaurant dataset to understand restaurant trends and customer behavior such as ratings, votes, pricing, and online ordering.

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Key Insights
- Certain restaurant types receive higher customer engagement in terms of votes
- Online ordering is widely adopted among restaurants
- Most ratings fall within a moderate range
- Majority of restaurants are affordable to mid-range priced
